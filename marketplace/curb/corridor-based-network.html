Corridor-Based Network

Two markets with distinct dynamics, not one homogeneous model.
Local / dense delivery
Root density, already covered by the network effect — a local courier for a bulky object (e.g. a sofa within 20km).
Cross-border corridor
A carrier making a regular or occasional trip between two specific zones (e.g. Zurich–Germany) — not a dense mesh, not global reach: point-to-point routes.

The term is kept as-is: corridor-based — no dilution with generic values like "regional" or "national," which add no information about the actual mechanism.
